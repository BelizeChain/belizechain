## Overview

### What is Maya Wallet?

Maya Wallet is BelizeChain's official wallet application for managing DALLA and bBZD.

**Named after**: Ancient Maya civilization (Belize's heritage) 🇧🇿

**Features**:
- ✅ Send/receive DALLA and bBZD
- ✅ Multiple accounts in one app
- ✅ QR code scanning
- ✅ Transaction history with search
- ✅ Governance voting
- ✅ Contact management
- ✅ Biometric security
- ✅ Offline balance viewing

**Platforms**: iOS, Android, Windows, Mac, Linux

### Create Additional Accounts

**Why?** Separate personal/business funds, organize savings, privacy

**Steps**:
1. Tap **☰ Menu** (top right)
2. Tap **"Accounts"**
3. Tap **"+ Create New Account"**
4. Enter account name:
   - "Personal Spending"
   - "Business Income"
   - "Savings"
   - "Family Fund"
5. Choose account type:
   - **Personal** (default)
   - **Business** (requires KYC)
   - **Savings** (long-term holding)
6. Tap **"Create"**
7. ✅ New account created!

**Note**: Each account has:
- Different address
- Separate balance
- Same 12-word backup phrase (all accounts restore together)

---

### Switch Between Accounts

**Method 1: Quick Switch**
1. Tap account name at top
2. List of accounts appears
3. Tap account to switch

**Method 2: Account Manager**
1. Tap **☰ Menu**
2. Tap **"Accounts"**
3. See all accounts with balances
4. Tap any account to switch

### Rename Account

## Sending Money

### Basic Send

**Quick guide**: [Your First Transaction](../getting-started/your-first-transaction.md)

**Steps**:
1. Tap **"Send"** button
2. Enter recipient address (paste or scan QR)
3. Enter amount
4. Choose currency (DALLA or bBZD)
5. Add memo (optional)
6. Review details
7. Tap **"Send"**
8. Confirm with PIN/biometric
9. ✅ Sent in 6 seconds!

---

### Send to Contact

**Save frequent recipients!**

**First, add contact**:
1. **☰ Menu → Contacts**
2. Tap **"+ Add Contact"**
3. Enter:
   - Name: "Mom"
   - Address: `5Grwva...` (paste or scan)
   - Note: "Maria - Dangriga" (optional)
4. Tap **"Save"**

**Now send to contact**:
1. Tap **"Send"**
2. Tap **"To:"** field
3. Tap **📇 Contacts** icon
4. Select "Mom" from list
5. ✅ Address auto-fills!
6. Enter amount and send

---

### Scan QR Code to Send

**Easiest method for in-person payments!**

1. Tap **"Send"**
2. Tap **📷 QR scanner** icon
3. Point camera at recipient's QR code
4. ✅ Address automatically fills
5. Amount may auto-fill too (if encoded in QR)
6. Confirm and send

**Tip**: Recipient shows their QR by tapping "Receive" in their wallet

---

### Send Maximum Available

Want to send everything?

1. Tap **"Send"**
2. In amount field, tap **"Max"** button
3. ✅ Automatically calculates: Balance - Fee
4. Review and send

**Example**:
- Balance: 100 DALLA
- Tap "Max"
- Shows: 99.99 DALLA (leaving 0.01 for fee)

## Receiving Money

### Show Your QR Code

**Easiest way to receive payments!**

1. Tap **"Receive"** button
2. Your QR code appears (big square)
3. Let sender scan it with their phone
4. ✅ Done! Wait for payment (6 seconds)

**QR code contains**: Your wallet address

---

### Copy Your Address

**For sending via text/email/WhatsApp**:

1. Tap **"Receive"**
2. Tap **"Copy Address"** button
3. ✅ Address copied to clipboard
4. Paste into message and send

**Or**: Tap 📋 icon next to address on main screen

---

### Share Address

**Send address via any app**:

1. Tap **"Receive"**
2. Tap **"Share"** button
3. Choose app:
   - WhatsApp
   - SMS
   - Email
   - Messenger
   - etc.
4. Select contact
5. Message with address sends automatically

---

### Request Specific Amount

**Create payment request with amount included**:

1. Tap **"Receive"**
2. Tap **"Request Amount"**
3. Enter amount: `50`
4. Choose currency: bBZD
5. Add message: "For lunch" (optional)
6. Tap **"Generate Request"**
7. QR code updates with amount included
8. Share QR or link

**When sender scans**: Amount auto-fills! They just tap "Send"

---

### Multiple Receive Addresses

**Privacy tip**: Generate new addresses for different purposes

1. **☰ Menu → Addresses**
2. Tap **"+ Generate New"**
3. Label it: "Business", "Freelance", "Donations"
4. ✅ New address created (same wallet)

- Different people don't see each other's payments

- Easier tracking (which address got paid)

## Transaction History

1. Tap **"History"** tab at bottom
2. See list of all transactions:
   - ⬇️ **Green** = Received
   - ⬆️ **Red** = Sent

   - ⚙️ **Gray** = Other actions

**Each shows**:
- Amount
- Time/date
- Who sent/received
- Status (Complete, Pending, Failed)
- Memo (if any)

## Security

### Backup Your Wallet

**CRITICAL**: Without backup, lost phone = lost money!

**View your backup phrase**:
1. **☰ Menu → Settings → Security**
2. Tap **"Backup Wallet"**
3. Enter PIN/use biometric
4. ⚠️ **12 words appear**
5. **Write them on paper** (DO NOT screenshot!)
6. Verify you wrote them correctly
7. Hide paper somewhere safe

**Test your backup**:
1. **Settings → Security → Verify Backup**
2. Enter words in order
3. ✅ Correct? Backup is good!

---

### Enable Biometric Login

**Faster, more secure than PIN**:

1. **☰ Menu → Settings → Security**
2. Tap **"Biometric Login"**
3. Toggle **ON**
4. Authenticate with Face ID / Touch ID / Fingerprint
5. ✅ Now use biometric to open wallet

**Note**: PIN still works as backup

---

### Change PIN

1. **☰ Menu → Settings → Security**
2. Tap **"Change PIN"**
3. Enter current PIN
4. Enter new PIN (6 digits)
5. Confirm new PIN
6. ✅ PIN updated

---

### Transaction Confirmation

**Always confirm large transactions**:

1. **Settings → Security → Transaction Limits**
2. Set **"Always Confirm"** threshold
3. Example: 100 bBZD
4. ✅ Transactions over 100 bBZD require extra confirmation

---

### Security Checkup

**Check your security score**:

1. **☰ Menu → Settings → Security**
2. Tap **"Security Checkup"**
3. See checklist:
   - ✅ Backup phrase saved: YES
   - ✅ Biometric enabled: YES
   - ✅ Auto-lock enabled: YES
   - ❌ 2FA enabled: NO
   - **Score: 75/100**
4. Tap items to improve

## Troubleshooting

**Detailed guide**: [Troubleshooting Guide](./troubleshooting.md)

### Common Issues

**"Can't connect to network"**
- Check internet connection
- Try different WiFi
- Restart app
- Update to latest version

**"Transaction pending forever"**
- Wait 60 seconds
- Check internet
- Restart app
- If > 5 minutes, contact support

**"Wrong balance showing"**
- Pull to refresh
- Check you're on correct network (mainnet vs testnet)
- Check correct account selected
- Clear cache: Settings → Advanced → Clear Cache

**"Forgot PIN"**
- Tap "Forgot PIN?"
- Use biometric if enabled
- **OR** restore wallet with 12 words
- ⚠️ If no backup: money is lost forever

**"App crashes on startup"**
- Update to latest version
- Restart phone
- Clear app cache
- Reinstall app (safe with backup!)
- Contact support if continues

## Tips & Tricks

### Speed Tips

**Fastest send**:
1. Add frequent recipients as contacts
2. Use QR codes for in-person
3. Enable biometric (skip PIN)
4. Use "Send to Recent" quick action

---

### Save Money

**Batch payments**: Send to multiple people in one transaction = one fee
- Example: Pay 50 employees with 0.05 fee vs. 50×0.01 = 0.50

**Use bBZD for daily payments**: Stable value, no price fluctuation risk

**DALLA for savings**: Potential to increase in value over time
