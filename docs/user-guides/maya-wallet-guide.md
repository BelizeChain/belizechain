## Getting Started

### Download Maya Wallet

**iOS:** App Store → Search "Maya Wallet Belize"
**Android:** Google Play → Search "Maya Wallet Belize"  
**Web:** https://maya.belizechain.org

### Create Account

1. Open Maya Wallet
2. Tap **Create New Account**
3. Write down 12-word seed phrase (keep ultra-secure!)
4. Verify seed phrase by selecting words in order
5. Create 6-digit PIN
6. ✅ Account created!

**Your addresses:**
- **DALLA address:** 5GrwvaEF... (for native token)
- **bBZD address:** Same address, different token

## Complete KYC

### Basic KYC (Instant, Free)

**Required for:**
- Receive up to 1,000 DALLA/month
- View balance and transaction history

**Steps:**
1. Settings → Identity → Apply for Basic KYC
2. Enter email address (verify via code)
3. Enter phone number (SMS verification)
4. ✅ Basic KYC approved instantly

### Verified KYC (1-3 days, Free)

**Required for:**
- Send DALLA/bBZD
- Full daily limits (10,000 DALLA/day)
- Staking (earn rewards)
- Tourism cashback
- BNS domain registration

**Steps:**
1. Settings → Identity → Upgrade to Verified
2. Take photo of passport or BelizeID (front + back)
3. Take selfie holding ID
4. Upload proof of address (utility bill <3 months)
5. Submit application
6. Wait 1-3 business days for FSC approval
7. ✅ Verified KYC approved (push notification)

## Sending & Receiving Payments

### Receive DALLA/bBZD

```
1. Home → Receive
2. Share QR code OR copy address
3. Sender scans QR or enters address
4. ✅ Funds arrive within 6 seconds (1 block)
```

**Transaction fee:** 0.01 DALLA (≈ $0.003)

### Send DALLA

```
1. Home → Send
2. Scan recipient QR code OR paste address
3. Enter amount (e.g., 100 DALLA)
4. Review details:
   - Recipient: 5FHneW4A...
   - Amount: 100 DALLA
   - Fee: 0.01 DALLA
   - Total: 100.01 DALLA
5. Enter PIN to confirm
6. ✅ Transaction submitted
```

**Confirmation time:** 6 seconds (1 block)

### Send bBZD (Stablecoin)

Same process as DALLA, but select **bBZD** token instead.

**Use cases:**
- Pay merchants (1:1 with BZD dollar)
- Remittances (stable value, no DALLA volatility)
- Savings (protected from inflation)

## Staking (Earn 544% APY)

### Nominate Validators

**Minimum:** 1,000 DALLA (≈ $300 @ $0.30/DALLA)

**Steps:**
1. Home → Staking → Nominate Validators
2. Select up to 16 validators (diversify for safety)
   - Check validator performance:
     - **Uptime:** >99% (green checkmark)
     - **Commission:** <15% (lower is better)
     - **Total stake:** Look for mid-sized (not smallest or largest)
3. Enter stake amount (e.g., 10,000 DALLA)
4. Review rewards estimate:
   - **Stake:** 10,000 DALLA
   - **APY:** 544% (assumes 10% commission)
   - **Effective APY:** 489.6% after commission
   - **Monthly rewards:** ~4,080 DALLA
   - **Annual rewards:** ~49,000 DALLA
5. Enter PIN to confirm
6. ✅ Staking active after 6 hours (1 era)

### View Rewards

```
Home → Staking → My Rewards

Current stake: 10,000 DALLA
Total rewards earned: 4,856 DALLA (1 month)
Pending rewards: 127 DALLA (unbonded in 2 hours)

Options:
- Compound (re-stake automatically)
- Claim (withdraw to wallet)
```

### Unstake (Withdraw)

```
1. Home → Staking → Unbond
2. Enter amount to unstake (e.g., 5,000 DALLA)
3. Wait 28 days (unbonding period)
4. Claim unbonded tokens
5. ✅ Funds available in wallet
```

**Note:** Unbonding takes 28 days for security (prevent flash stake attacks)

1. ✅ **Backup seed phrase** on paper (not screenshots!)

4. ✅ **Verify addresses** before sending (last 4 characters minimum)

## Troubleshooting

### Transaction Stuck (Pending)

**Wait 1 minute** → If still pending:
1. Home → Activity → View transaction
2. Check block explorer: https://explorer.belizechain.org
3. Contact support if not confirmed after 5 minutes

### Forgot PIN

1. Settings → Security → Reset PIN
2. Enter 12-word seed phrase
3. Create new PIN
4. ✅ PIN reset

**If seed phrase lost:** Funds are **unrecoverable** (by design for security)

### bBZD Not Showing

1. Home → Manage Tokens
2. Enable "bBZD Stablecoin" toggle
3. ✅ bBZD now visible
