## 💳 Point of Sale (POS) Integration

### For Retail Stores

**Option 1: Maya Wallet Tablet**
- Use tablet/phone as POS
- Built-in calculator
- Receipt printer (Bluetooth)
- Daily reports

**Option 2: POS System Integration**
- Integrate with existing POS
- API connection
- Automatic reconciliation
- Works with most POS systems

**Popular compatible POS**:
- Clover
- Square
- Toast (restaurants)
- Shopify POS
- Lightspeed

### Setup POS Integration

**Step 1: Get API Credentials**

1. Maya Wallet → **Menu** → **"Business Settings"** → **"API Access"**
2. Click **"Generate API Key"**
3. Save credentials:
```
API Key: bzc_live_abc123...
Secret: bzc_secret_xyz789...
Webhook URL: https://yourbusiness.com/webhook
```

**Step 2: Install Plugin**

```bash
# For Shopify
https://apps.shopify.com/belizechain-payments

# For WooCommerce
wp plugin install belizechain-payments

# For custom integration
npm install @belizechain/payment-sdk
```

**Step 3: Configure**

```javascript
// Example configuration
const BelizeChain = require('@belizechain/payment-sdk');

const payment = new BelizeChain({
  apiKey: 'bzc_live_abc123...',
  apiSecret: 'bzc_secret_xyz789...',
  network: 'mainnet',
  webhook: 'https://yourbusiness.com/webhook'
});

// Create payment request
const request = await payment.createInvoice({
  amount: 45.00,
  currency: 'bBZD',
  description: 'Lunch order #1234',
  metadata: {
    table: 5,
    server: 'Maria'
  }
});

console.log(request.qrCode); // QR code URL
console.log(request.paymentUrl); // Payment link
```

**Step 4: Test**

1. Create test transaction
2. Scan QR code with Maya Wallet (testnet mode)
3. Verify webhook received
4. Check reconciliation

**Step 5: Go Live!**

Switch to mainnet and start accepting payments!

```javascript
// Create recurring payment

  // Notify customer, suspend access
});

payment.on('subscription.cancelled', (event) => {
  console.log('Subscription cancelled');
  // End access, send farewell email
});
```

## 🔒 Security Best Practices

### Protect Your Business Account

**1. Strong PIN**
- ✅ Use 6-digit PIN (not 123456!)
- ✅ Change regularly
- ❌ Don't share with employees (use separate accounts)

**2. Backup Phrase**
- ✅ Write down 12 words
- ✅ Store in safe/bank vault
- ❌ Never digital (photo, email, cloud)
- ❌ Never share with anyone

**3. Employee Accounts**
- ✅ Create separate account for each employee
- ✅ Set permissions (view-only, can refund, etc.)
- ✅ Track activity
- ❌ Don't share master account

**4. Regular Reconciliation**
- ✅ Check daily
- ✅ Match with POS
- ✅ Investigate discrepancies
- ✅ Export to accounting weekly

**5. Secure Devices**
- ✅ Use device lock
- ✅ Install antivirus
- ✅ Keep software updated
- ❌ Don't use on public WiFi (use VPN)
