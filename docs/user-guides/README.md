## 💡 Quick Tips

### Security
- Never share your 12-word backup phrase
- Enable biometric login (face/fingerprint)
- Start with small transactions
- Double-check addresses before sending

### Fees
- Most transactions: $0.01
- Batch payments: $0.05
- Receiving: FREE
- Voting: $0.01

### Speed
- Transaction time: 6 seconds
- Block time: 6 seconds
- Finality: Immediate

### Support
- Phone: +501-CHAIN (24246)
- Email: support@belizechain.org
- Hours: 24/7
- Response: Usually within 1 hour
