## 📚 Available Tutorials

### Basic Tutorials

#### 💸 [Send Batch Payments](./send-batch-payments.md)
**Pay multiple people at once (save fees!)**

**What you'll learn**:
- Setup batch payment in Maya Wallet
- Import recipient list (CSV)
- Preview and confirm batch
- Track all payments
- Common use case: Payroll

**Time**: 20 minutes  
**Level**: ⭐ Easy  
**Saves**: 90% on fees!

**Example**: Pay 50 employees:
- Old way: 50 transactions × $0.01 = $0.50
- Batch way: 1 transaction = $0.05
- **Savings**: $0.45 per payroll
