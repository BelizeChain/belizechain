## 🎯 What is BelizeID?

**BelizeID** is your **digital identity** on BelizeChain that:

- 🔐 **You control** (not government, not companies)
- 🌐 **Works everywhere** (all BelizeChain apps)
- 🔒 **Protects privacy** (share only what's needed)
- ✅ **Government-verified** (trusted credentials)
- 📱 **Mobile-friendly** (in your Maya Wallet)

### **Real-World Examples**

| Situation | Instead of... | Use BelizeID... |
|-----------|---------------|-----------------|
| **Buy alcohol** | Show physical ID (exposes address, ID#) | Prove age >18 ✅ |
| **Apply for loan** | Submit pay stubs, bank statements | Prove income >$2K/mo ✅ |
| **Rent car** | Leave copy of driver's license | Prove valid license ✅ |
| **Open bank account** | Fill out forms, wait days | Instant KYC verification ✅ |
| **Prove residency** | Utility bills, lease | Prove Belize resident ✅ |
| **Age-restricted content** | Create account with birthdate | Prove age anonymously ✅ |

**Key Benefit**: Share *proof* without revealing *details*!

### **How Do Credentials Work?**

**Traditional way** (privacy nightmare):
```
Store asks for ID → You show full ID card
↓
They see EVERYTHING:
• Your full name
• Your address
• Your ID number
• Your photo
• Your signature
```

**BelizeID way** (privacy-preserving):
```
Store asks for age proof → You prove "Over 18"
↓
They ONLY learn:
• You are over 18 ✅
• Nothing else! (no name, no address, nothing)
```

**Magic**: Zero-knowledge proofs! You prove something is true without revealing the data! 🪄

## 🐛 Troubleshooting

### **Problem: ID Verification Rejected**

**Symptoms**: "Your ID verification was rejected."

**Solutions**:

1. **Check photo quality**:
   - ✅ All 4 corners visible
   - ✅ Good lighting (no glare)
   - ✅ Text readable
   - ✅ Not blurry

2. **Try again with better lighting**:
   - Daylight works best
   - Avoid direct sunlight (causes glare)
   - Use a lamp if indoors

3. **Check ID is valid**:
   - Not expired
   - Not damaged
   - Official government ID

4. **Contact support**:
   - Email: identity@belizechain.org
   - Phone: +501-ID-HELP (43-4357)

---

### **Problem: Can't Recover BelizeID**

**Symptoms**: Recovery phrase not working.

**Solutions**:

1. **Check spelling carefully**:
   - "ocean" not "Ocean" (lowercase)
   - No extra spaces
   - Correct order (word #1, #2, etc.)

2. **Try alternative phrase format**:
   - Some wallets use different word lists
   - Check if you saved in different language

3. **Check backup location**:
   - Did you write it elsewhere?
   - Email backup?
   - Family member has copy?

4. **Last resort - create new BelizeID**:
   - Unfortunately, without recovery phrase, BelizeID is lost
   - Create new one
   - Re-verify credentials
   - **This time**: Safely store recovery phrase!

---

### **Problem: Credential Request Declined**

**Symptoms**: "Merchant declined your credential."

**Solutions**:

1. **Credential expired**:
   - Check expiration date
   - Re-verify if needed

2. **Merchant requires different credential**:
   - Read request carefully
   - You might need additional verification

3. **Technical issue**:
   - Try again
   - Restart Maya Wallet
   - Check internet connection

4. **Contact merchant**:
   - They might need to fix their integration
