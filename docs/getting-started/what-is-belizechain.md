## 💰 What Currency Does it Use?

BelizeChain has TWO types of money:

### 1. DALLA 🌴
**Belize's native cryptocurrency**

- Named after the Belize Dollar (we say "DALLA" in Creole!)
- Value goes up and down (like stocks)
- Good for: Savings, investments, long-term holding
- Example: 1 DALLA might be worth $2 today, $2.50 tomorrow

### 2. bBZD 💵
**Belize Dollar Stablecoin** (pegged to BZD)

- Always worth same as Belize Dollar (central bank governed)
- Value NEVER changes
- Good for: Daily payments, bills, salary
- Example: 1 bBZD = BZ$1 BZD forever

**Which should you use?**
- Pay bills? Use **bBZD** (stable)
- Save for future? Use **DALLA** (can grow in value)
